# Contributing

Please include the following with bug reports:

```bash
./diagnose.sh > diagnose.txt 2>&1
```

Also include:

- ODROID model
- `uname -a`
- `lsusb`
- exact USB ID
- compiler version (`gcc --version | head -1`)
- whether the AP is 2.4 GHz, 5 GHz, or dual-band with a shared SSID

Do not post Wi-Fi passwords, private keys, access tokens, or account passwords.
